About this project

5개 덱의 턴제 물리 충돌 전투

도넛 5장의 덱을 구성하고 턴마다 한 장씩 발사하는 충돌 기반 전투 로직을 설계했습니다. 속도, 질량, 충돌 각도가 데미지 계산에 직접 반영되어 단순한 카드 게임이 아닌 물리적 직관이 작동하는 전투를 만들었습니다.

정밀한 데미지 공식 설계

DMG = (ATK − DEF) × Speed/10 의 기본 공식을 시작으로 크리티컬, 최소 피해 보장, 예외 처리까지 단일 플로우차트로 정리했습니다. 단 1의 수치 차이가 만드는 타격감을 시뮬레이션으로 검증했습니다.

모듈화된 스킬 시스템

도넛별 고유 스킬을 데이터 테이블 기반으로 구조화하여 확장과 수정이 용이하도록 설계했습니다. 동일 효과의 스킬은 중첩되지 않고 지속 시간만 갱신되는 일관성 규칙을 정립했습니다.

About this project

타워로 경로를 직접 설계

기존 TD의 고정 경로에서 벗어나 매 게임마다 무작위 경로가 생성되고, 플레이어가 타워 배치로 적의 동선을 유도합니다. 도착 지점만 막지 않으면 자유롭게 배치 가능한 주도적 설계의 재미를 제공합니다.

4종족 시너지 시스템

인간, 엘프, 드워프, 용족 4종족 타워를 조합하여 공격력, 공격속도, 적 감속, 골드 수급 등 고유 시너지를 발동합니다. 종족 조합과 상점 구성에 따라 유저 맞춤형 전략 설계가 가능합니다.

엑셀 기반 웨이브 밸런싱

몬스터의 이동 속도와 체력 증가 폭을 엑셀 시뮬레이션으로 검증하여 후반부 긴장감을 유지하는 난이도 곡선을 설계했습니다. 타워별 데미지 효율을 계산해 특정 타워만 선호되는 현상을 방지했습니다.

About this project

직관적인 게임 루프

터치 → 재화 획득 → 성장 재투자의 단순 루프로 즉각적인 보상과 성취감을 제공합니다. 복잡한 조작 없이도 자연스럽게 성장 동기가 유지되는 구조를 설계했습니다.

장기 플레이를 위한 경제 구조

재화의 생성과 소모 구조를 데이터로 구조화하여 연구, 장소 해금, 서브 캐릭터 해금 등 다층 소모처를 설계했습니다. 인플레이션 관리로 후반부에도 성장 동기가 유지되도록 밸런싱했습니다.

광고 수익 모델 연동

성장이 둔화되는 지점을 의도적으로 설계하고, 이를 극복하기 위한 보상을 광고 시청과 결합하여 자연스러운 수익 발생 구조를 만들었습니다. 유저 경험을 해치지 않는 시점을 데이터로 검증했습니다.
